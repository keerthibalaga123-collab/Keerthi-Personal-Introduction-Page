# Keerthi Balaga — Personal Introduction Page

A responsive single-page personal introduction website created for the Veda Technology Web Development internship task.

## Technologies

- HTML5
- CSS3
- Responsive design
- No external libraries required

## Sections

- Home
- About
- Skills
- Hobbies
- Contact

## Project Structure

```text
Keerthi-Personal-Introduction-Page/
├── index.html
├── style.css
├── README.md
├── DEPLOYMENT.md
└── assets/
    └── profile.svg
```

## Run Locally

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser.

For a VS Code workflow, install the Live Server extension and open `index.html` with Live Server.

## Before Submission

Replace the placeholder email in `index.html`:

```html
your-email@example.com
```

with your real email address.

You can also replace `assets/profile.svg` with your own profile photo. If you do this, update the image filename in `index.html`.
